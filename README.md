# Hotel Management — Django

Django hotel booking project with rooms, booking forms, checkout, invoice and payment-status templates.

## Project structure

- `hotel_management/`
- `main/models.py`
- `main/forms.py`
- `main/views.py`
- `main/templates/main/`
- `manage.py`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/hotel-management.git
cd hotel-management
```

Create a Python virtual environment, install Django and dependencies required by the source, configure settings locally, then run `python manage.py migrate` and `python manage.py runserver`.
